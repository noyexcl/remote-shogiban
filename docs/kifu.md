# 棋譜貼り付け

CTRL + V が押されたら、現在の棋譜をクリアし、クリップボードの kif 形式ファイルを Kifu オブジェクトに変換して現在の状態にセットする

クリップボードの値は不正な形式の場合も考慮しなければならない
その場合、単に現在の棋譜をクリアして Console にエラーメッセージを出力するだけで良い

# 棋譜例

```text
手合割：平手
先手：
後手：
手数----指手---------消費時間--
   1 ７六歩(77)        ( 0:00/00:00:00)
   2 ３四歩(33)        ( 0:00/00:00:00)

変化：2手
   2 ８四歩(83)        ( 0:00/00:00:00)
   3 ２六歩(27)        ( 0:00/00:00:00)
   4 ８五歩(84)        ( 0:00/00:00:00)
*コメント
   5 ７七角(88)        ( 0:00/00:00:00)
```
